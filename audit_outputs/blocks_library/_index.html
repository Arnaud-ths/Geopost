Geopost · Blocks Library v1

Librairie de blocs email

17 blocs conformes — Outlook 2007 → M365 · WCAG 2.1 AA · Dark mode · Mobile responsive · Multi-brand tokens

11 mai 2026 · Geopost Lead CRM V1

Comment utiliser cette librairie

Chaque bloc est standalone et paramétrable via tokens {{TOKEN}}. Le wrapper (01) enveloppe les autres blocs. La composition d'un email = wrapper + preheader + header + héro + (1-3 blocs body) + CTA + footer + tracking pixel. Aperçus ci-dessous rendus avec les valeurs par défaut Geopost corporate — à substituer par les tokens BU réels en production.

  ===========================
